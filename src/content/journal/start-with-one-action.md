## Write the task in the visitor’s words

Before drawing the page, finish the sentence “I came here to…”. For a portfolio, the answer might be “see an example of interface work” or “find out how to get in touch”. Pick one for the first sketch.

## Test the path from the opening screen

Give someone the task without explaining the layout. Watch the first link they choose. If they pause between two similar buttons, change one label and try again. Keep the version that makes the destination clearer.
